# Grid Quest — 2D Game Bootstrap

A turn-based console grid game written in Java for the Epitech 2D Game bootstrap.

The hero (`@`) moves around a 5×5 grid, fights enemies (`E`), and picks up
items (`I`) until either all enemies are defeated (victory) or the hero's
HP reaches 0 (game over).

## How to run

From the project root:

```bash
javac *.java
java Main
